Frequently Asked Questions প্রায়শই জিজ্ঞাসিত প্রশ্ন

Find answers to common questions about Alif Shohoj Print. Alif Shohoj Print সম্পর্কে সাধারণ প্রশ্নের উত্তর খুঁজুন।

What is Alif Shohoj Print? Alif Shohoj Print কী? +
Alif Shohoj Print is a complete print shop management solution. It combines a Shop POS (point of sale) with a Windows desktop print agent. You can manage orders, print jobs, customer service, and reports — all from one app. Alif Shohoj Print একটি সম্পূর্ণ প্রিন্ট শপ ম্যানেজমেন্ট সলিউশন। এটি একটি Shop POS (পয়েন্ট অফ সেল) এবং Windows ডেস্কটপ প্রিন্ট এজেন্ট একত্রিত করে। আপনি অর্ডার, প্রিন্ট জব, কাস্টমার সার্ভিস, এবং রিপোর্ট ম্যানেজ করতে পারেন — সব এক অ্যাপ থেকে।
Is it free to use? এটি কি বিনামূল্যে ব্যবহারযোগ্য? +
Yes! Alif Shohoj Print is free to download and use. No subscription, no hidden fees. It's open-source. হ্যাঁ! Alif Shohoj Print বিনামূল্যে ডাউনলোড এবং ব্যবহার করা যায়। কোনো সাবস্ক্রিপশন নেই, কোনো হিডেন ফি নেই। এটি ওপেন-সোর্স।
What Windows versions are supported? কোন Windows ভার্সন সাপোর্টেড? +
Windows 10 and Windows 11 (both 64-bit and 32-bit). The installer auto-detects your architecture. Windows 10 এবং Windows 11 (৬৪-bit এবং ৩২-bit উভয়)। ইনস্টলার অটো-ডিটেক্ট করে আপনার আর্কিটেকচার।
Do I need an internet connection? ইন্টারনেট কানেকশন প্রয়োজন? +
No! Core features work completely offline. Internet is only needed for customer PWA (LAN) and voice clip generation. না! কোর ফিচারগুলো সম্পূর্ণ অফলাইনে কাজ করে। ইন্টারনেট শুধু কাস্টমার PWA (LAN) এবং ভয়েস ক্লিপ জেনারেশনের জন্য প্রয়োজন।
How does printing work? প্রিন্টিং কীভাবে কাজ করে? +
The app uses SumatraPDF for silent printing. Jobs are queued in SQLite, then sent to your installed Windows printer. The print agent runs in the system tray. অ্যাপ SumatraPDF ব্যবহার করে সাইলেন্ট প্রিন্টিংয়ের জন্য। জবগুলো SQLite-এ কিউ হয়, তারপর আপনার ইনস্টল করা Windows প্রিন্টারে পাঠানো হয়। প্রিন্ট এজেন্ট সিস্টেম ট্রেতে রান করে।
Can I use multiple counters? একাধিক কাউন্টার ব্যবহার করতে পারি? +
Yes! Set up multiple counter PCs. Each counter has its own QR code and order feed. All printing happens on the master PC. হ্যাঁ! একাধিক কাউন্টার PC সেটআপ করুন। প্রতিটি কাউন্টারের নিজস্ব QR কোড এবং অর্ডার ফিড আছে। সব প্রিন্টিং মাস্টার PC-তে হয়।
Is my data safe? আমার ডেটা কি নিরাপদ? +
Yes. All data is stored locally on your PC. No cloud, no external servers. The WebSocket token is stored with Windows DPAPI encryption for counter keys. হ্যাঁ। সব ডেটা আপনার PC-তে লোকালি সংরক্ষিত। কোনো ক্লাউড নেই, কোনো এক্সটার্নাল সার্ভার নেই। কাউন্টার কী-এর জন্য WebSocket টোকেন Windows DPAPI এনক্রিপশন দিয়ে সংরক্ষিত।
Can customers pay online? কাস্টমাররা কি অনলাইন পেমেন্ট করতে পারে? +
Currently, payment is counter cash only. Customers submit orders as unpaid, and staff confirm cash payment at the counter. Online payment (bKash/Nagad) is planned for a future version. বর্তমানে, পেমেন্ট শুধু কাউন্টার ক্যাশ। কাস্টমাররা অর্ডার আনপেইড হিসেবে সাবমিট করে, এবং স্টাফ কাউন্টারে ক্যাশ পেমেন্ট কনফার্ম করে। অনলাইন পেমেন্ট (bKash/Nagad) ভবিষ্যত ভার্সনে প্ল্যানড।
How do I update the app? অ্যাপ কীভাবে আপডেট করব? +
Download the latest installer from the Download page or GitHub Releases. Run it — it will update your existing installation while preserving your data. ডাউনলোড পেইজ বা GitHub Releases থেকে লেটেস্ট ইনস্টলার ডাউনলোড করুন। রান করুন — এটি আপনার এক্সিস্টিং ইনস্টলেশন আপডেট করবে এবং আপনার ডেটা সংরক্ষণ করবে।
Can I edit customer images? কাস্টমার ইমেজ এডিট করতে পারি? +
Yes! The built-in Studio editor lets you crop, rotate, adjust colors, remove backgrounds, add watermarks, and more. Original images are never overwritten. হ্যাঁ! বিল্ট-ইন স্টুডিও এডিটর দিয়ে আপনি ক্রপ, রোটেট, কালার অ্যাডজাস্ট, ব্যাকগ্রাউন্ড রিমুভ, ওয়াটারমার্ক যোগ এবং আরও অনেক কিছু করতে পারেন। অরিজিনাল ইমেজ কখনো ওভাররাইট হয় না।
What file formats are supported for printing? প্রিন্টিংয়ের জন্য কোন ফাইল ফরম্যাট সাপোর্টেড? +
PDF, JPEG, and PNG. Maximum file size: 40 MiB. Files are validated before queuing. PDF, JPEG, এবং PNG। সর্বোচ্চ ফাইল সাইজ: ৪০ MiB। কিউ করার আগে ফাইল ভ্যালিডেট করা হয়।
