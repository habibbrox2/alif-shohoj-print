Installation Note ইনস্টলেশন নোট

The installer is unsigned and may trigger Windows SmartScreen. Click "More info" → "Run anyway" to proceed. This is normal for open-source apps without a code signing certificate. ইনস্টলারটি আনসাইনড এবং Windows SmartScreen ট্রিগার করতে পারে। "More info" → "Run anyway" ক্লিক করে এগিয়ে যান। কোড সাইনিং সার্টিফিকেট ছাড়া ওপেন-সোর্স অ্যাপের জন্য এটি স্বাভাবিক।

Installation Steps ইনস্টলেশন ধাপ

1

Download ডাউনলোড

Download the installer for your Windows architecture (x64 or 32-bit). আপনার Windows আর্কিটেকচারের (x64 বা 32-bit) জন্য ইনস্টলার ডাউনলোড করুন।

2

Install ইনস্টল

Run the installer. Choose installation directory. Shortcuts created automatically. ইনস্টলার রান করুন। ইনস্টলেশন ডিরেক্টরি বেছে নিন। শর্টকাট স্বয়ংক্রিয়ভাবে তৈরি হবে।

3

First Launch প্রথম লঞ্চ

Choose master or counter PC mode. Set up printers and WebSocket token. মাস্টার বা কাউন্টার PC মোড বেছে নিন। প্রিন্টার ও WebSocket token সেটআপ করুন।

4

Start Using ব্যবহার শুরু

Create orders, print jobs, and serve customers. You're ready! অর্ডার তৈরি, প্রিন্ট জব, এবং কাস্টমার সার্ভ করুন। আপনি প্রস্তুত!
