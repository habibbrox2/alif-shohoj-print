Step-by-Step Tutorial স্টেপ-বাই-স্টেপ টিউটোরিয়াল

Get up and running with Alif Shohoj Print in minutes. কয়েক মিনিটে Alif Shohoj Print দিয়ে শুরু করুন।

1

Download & Install ডাউনলোড ও ইনস্টল

Download the installer from the Download page. Run it and follow the wizard. The app installs to Program Files and creates shortcuts. ডাউনলোড পেইজ থেকে ইনস্টলার ডাউনলোড করুন। রান করুন এবং উইজার্ড ফলো করুন। অ্যাপ Program Files-এ ইনস্টল হয় এবং শর্টকাট তৈরি করে।

2

Choose PC Mode PC মোড বেছে নিন

On first launch, choose "Master PC" (shopkeeper) or "Counter PC" (operator). Master PC has full access. Counter PC has restricted access. প্রথম লঞ্চে, "Master PC" (শপকিপার) বা "Counter PC" (অপারেটর) বেছে নিন। মাস্টার PC-এর সম্পূর্ণ অ্যাক্সেস আছে। কাউন্টার PC-এর সীমিত অ্যাক্সেস আছে।

3

Set Up Printers প্রিন্টার সেটআপ

Open Settings → Printers (or Windows Agent window). The app auto-detects installed Windows printers. Select which printers to use for different paper types. Settings → Printers ওপেন করুন (বা Windows Agent উইন্ডো)। অ্যাপ অটো-ডিটেক্ট করে ইনস্টল করা Windows প্রিন্টার। বিভিন্ন পেপার টাইপের জন্য কোন প্রিন্টার ব্যবহার করবেন সিলেক্ট করুন।

4

Configure Services সার্ভিস কনফিগার

Go to Settings → Services. Add services from presets (ID card, A4 B/W, A4 Color, passport photo, etc.). Set pricing for each service. Settings → Services-এ যান। প্রিসেট থেকে সার্ভিস অ্যাড করুন (ID কার্ড, A4 B/W, A4 কালার, পাসপোর্ট ফটো ইত্যাদি)। প্রতিটি সার্ভিসের প্রাইসিং সেট করুন।

5

Set Business Hours ব্যবসায়িক সময় সেট

Go to Settings → Shop & Orders. Enable business hours and select open days with open/close times. Customer orders are only accepted during business hours. Settings → Shop & Orders-এ যান। ব্যবসায়িক সময় এনাবল করুন এবং ওপেন/ক্লোজ টাইম সহ ওপেন ডে সিলেক্ট করুন। ব্যবসায়িক সময়ের মধ্যেই শুধু কাস্টমার অর্ডার গ্রহণ করা হয়।

6

Set Up Customer PWA (Optional) কাস্টমার PWA সেটআপ (ঐচ্ছিক)

For customer self-ordering: Configure TLS certificate, enable gateway on port 43822, and print QR codes from Shop POS. Customers scan QR to order. কাস্টমার সেলফ-অর্ডারিংয়ের জন্য: TLS সার্টিফিকেট কনফিগার করুন, পোর্ট 43822-এ গেটওয়ে এনাবল করুন, এবং Shop POS থেকে QR কোড প্রিন্ট করুন। কাস্টমাররা অর্ডার করতে QR স্ক্যান করে।

7

Set Up Counter PC (Optional) কাউন্টার PC সেটআপ (ঐচ্ছিক)

Install on a second PC. Choose "Counter PC" mode. Enter master gateway URL and pairing key. Counter will show only its orders. দ্বিতীয় PC-তে ইনস্টল করুন। "Counter PC" মোড বেছে নিন। মাস্টার গেটওয়ে URL এবং পেয়ারিং কী এন্টার করুন। কাউন্টার শুধু তার অর্ডার দেখাবে।

8

Start Serving Customers! কাস্টমার সার্ভ শুরু করুন!

Create orders, edit images in Studio, approve and print. Track revenue and reports. You're ready to go! অর্ডার তৈরি, Studio-তে ইমেজ এডিট, অনুমোদন এবং প্রিন্ট করুন। রেভিনিউ এবং রিপোর্ট ট্র্যাক করুন। আপনি প্রস্তুত!
