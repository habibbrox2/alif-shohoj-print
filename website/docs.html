Getting Started শুরু করা

Installation ইনস্টলেশন

1. Download the installer from the Download page. ১. ডাউনলোড পেইজ থেকে ইনস্টলার ডাউনলোড করুন।

2. Run the installer. Choose installation directory (default: Program Files). ২. ইনস্টলার রান করুন। ইনস্টলেশন ডিরেক্টরি বেছে নিন (ডিফল্ট: Program Files)।

3. The installer creates Start Menu and desktop shortcuts. ৩. ইনস্টলার Start Menu এবং ডেস্কটপ শর্টকাট তৈরি করে।

4. Launch the app. On first run, choose whether this PC is the master (shopkeeper) or counter (operator) PC. ৪. অ্যাপ লঞ্চ করুন। প্রথম রানে, এই PC মাস্টার (শপকিপার) নাকি কাউন্টার (অপারেটর) PC তা বেছে নিন।

First Launch Setup প্রথম লঞ্চ সেটআপ

On the master PC: মাস্টার PC-তে:

  • Configure installed printers in Settings → PrintersSettings → Printers-এ ইনস্টল করা প্রিন্টার কনফিগার করুন
  • Set up services (ID card, A4 print, passport photo, etc.)সার্ভিস সেটআপ করুন (ID কার্ড, A4 প্রিন্ট, পাসপোর্ট ফটো ইত্যাদি)
  • Configure business hoursব্যবসায়িক সময় কনফিগার করুন
  • Set WebSocket token (auto-generated or custom)WebSocket token সেট করুন (অটো-জেনারেটেড বা কাস্টম)
  • Enable customer PWA gateway (port 43822)কাস্টমার PWA গেটওয়ে এনাবল করুন (পোর্ট 43822)

Master & Counter Setup মাস্টার ও কাউন্টার সেটআপ

Master PC মাস্টার PC

The master PC is the central hub. It runs the print agent, hosts the customer PWA, manages all orders, and performs all printing. মাস্টার PC হলো সেন্ট্রাল হাব। এটি প্রিন্ট এজেন্ট রান করে, কাস্টমার PWA হোস্ট করে, সব অর্ডার ম্যানেজ করে, এবং সব প্রিন্টিং সম্পাদন করে।

  • Dashboard with order inbox, job summary, printer fleetঅর্ডার ইনবক্স, জব সামারি, প্রিন্টার ফ্লিট সহ ড্যাশবোর্ড
  • Studio image editorস্টুডিও ইমেজ এডিটর
  • Reports (today & this month)রিপোর্ট (আজ ও এই মাস)
  • Settings (services, printers, business hours)সেটিংস (সার্ভিস, প্রিন্টার, ব্যবসায়িক সময়)
  • Customer PWA gateway (port 43822)কাস্টমার PWA গেটওয়ে (পোর্ট 43822)

Counter PC কাউন্টার PC

Counter PCs have restricted access. They show only the Counter Inbox with their orders. All printing happens on the master PC. কাউন্টার PC-এর সীমিত অ্যাক্সেস আছে। তারা শুধু Counter Inbox তাদের অর্ডার সহ দেখায়। সব প্রিন্টিং মাস্টার PC-তে হয়।

  • Locked Counter Inbox (no POS, no settings, no printers)লকড কাউন্টার ইনবক্স (কোনো POS, সেটিংস, প্রিন্টার নেই)
  • Counter pairing with master PC (encrypted key)মাস্টার PC-এর সাথে কাউন্টার পেয়ারিং (এনক্রিপ্টেড কী)
  • Counter QR code generationকাউন্টার QR কোড জেনারেশন
  • Heartbeat monitoring (online/offline status)হার্টবিট মনিটরিং (অনলাইন/অফলাইন স্ট্যাটাস)

Counter Pairing কাউন্টার পেয়ারিং

1. On master PC, open Shop POS → Counter QR poster → copy the pairing key. ১. মাস্টার PC-তে, Shop POS → Counter QR poster → পেয়ারিং কী কপি করুন।

2. On counter PC, enter the master gateway URL and pairing key during first-run setup or in Counter Inbox. ২. কাউন্টার PC-তে, প্রথম-রান সেটআপ বা Counter Inbox-এ মাস্টার গেটওয়ে URL এবং পেয়ারিং কী এন্টার করুন।

3. The key is stored encrypted (DPAPI) and never shown again. ৩. কী এনক্রিপ্টেড (DPAPI) স্টোর হয় এবং আর কখনো দেখানো হয় না।

WebSocket Protocol WebSocket প্রোটোকল

Authentication অথেন্টিকেশন

Clients must authenticate within 5 seconds of connecting: ক্লায়েন্টদের কানেক্ট করার ৫ সেকেন্ডের মধ্যে অথেন্টিকেট করতে হবে:

{"type":"auth","token":"<shared-token>"}

Server responds with: সার্ভার রেসপন্ড করে:

{"type":"authenticated"}

Job Submission জব সাবমিশন

{"type":"job","job":<PrintJob>}

The server validates the job, stores it in SQLite, and replies with an accepted message. Supported formats: PDF, JPEG, PNG (up to 40 MiB). সার্ভার জব ভ্যালিডেট করে, SQLite-এ সংরক্ষণ করে, এবং accepted মেসেজ রিপ্লাই করে। সাপোর্টেড ফরম্যাট: PDF, JPEG, PNG (৪০ MiB পর্যন্ত)।

⚠️
Note: Acceptance means the job is queued — not that printing is complete. নোট: Acceptance মানে জব কিউতে আছে — প্রিন্টিং সম্পন্ন হয়েছে তা নয়।

Print Agent Setup প্রিন্ট এজেন্ট সেটআপ

Authentication Token অথেন্টিকেশন টোকেন

On startup, the app uses ALIF_SHOHOJ_PRINT_WS_TOKEN if set. Otherwise, it reads/generates a token from Electron's user-data directory. The token is available in Shop POS settings. স্টার্টআপে, অ্যাপ ALIF_SHOHOJ_PRINT_WS_TOKEN ব্যবহার করে যদি সেট করা থাকে। না হলে, Electron-এর user-data ডিরেক্টরি থেকে টোকেন রিড/জেনারেট করে। টোকেন Shop POS settings-এ পাওয়া যায়।

Listener & TLS লিসেনার ও TLS

By default, the WebSocket listener binds to 127.0.0.1:43821. For LAN access, set host/port and TLS certificate/key environment variables. ডিফল্টরূপে, WebSocket লিসেনার 127.0.0.1:43821-এ বাইন্ড হয়। LAN অ্যাক্সেসের জন্য, host/port এবং TLS certificate/key এনভায়রনমেন্ট ভেরিয়েবল সেট করুন।

Queue & Printing কিউ ও প্রিন্টিং

  • Jobs stored in SQLite before acknowledgmentজবগুলো acknowledgment-এর আগে SQLite-এ সংরক্ষিত
  • Temporary PDFs staged and sent via SumatraPDFটেম্পোরারি PDF স্টেজ করে SumatraPDF এর মাধ্যমে পাঠানো
  • Source data removed after successful printসফল প্রিন্টের পর সোর্স ডেটা রিমুভ
  • Failed jobs retain source for retryফেইলড জবগুলো রিট্রাইয়ের জন্য সোর্স ধরে রাখে
  • Logs rotate at 5 MiB, 5 files retainedলগ ৫ MiB-এ রোটেট, ৫টি ফাইল ধরে রাখে

Customer PWA & Gateway কাস্টমার PWA ও গেটওয়ে

The master PC hosts the customer PWA and order gateway on port 43822. Customers scan a QR code to access the ordering app on their phone. মাস্টার PC পোর্ট 43822-এ কাস্টমার PWA এবং অর্ডার গেটওয়ে হোস্ট করে। কাস্টমাররা QR কোড স্ক্যান করে তাদের ফোনে অর্ডারিং অ্যাপ অ্যাক্সেস করে।

TLS Configuration TLS কনফিগারেশন

Set ALIF_SHOHOJ_PRINT_WS_TLS_CERT and ALIF_SHOHOJ_PRINT_WS_TLS_KEY for HTTPS. Both the PWA and gateway use HTTPS. Without TLS, the gateway listens on loopback only. HTTPS-এর জন্য ALIF_SHOHOJ_PRINT_WS_TLS_CERT এবং ALIF_SHOHOJ_PRINT_WS_TLS_KEY সেট করুন। PWA এবং গেটওয়ে উভয় HTTPS ব্যবহার করে। TLS ছাড়া, গেটওয়ে শুধু loopback-এ লিসেন করে।

Counter Order Feed কাউন্টার অর্ডার ফিড

Counter PCs read their orders from the master PC every 15 seconds via GET /api/counter-orders with x-counter-feed-key header. Feed is scoped to the counter that owns the key. কাউন্টার PC-গুলো প্রতি ১৫ সেকেন্ডে মাস্টার PC থেকে x-counter-feed-key হেডার সহ GET /api/counter-orders এর মাধ্যমে তাদের অর্ডার পড়ে। ফিড সেই কাউন্টারের জন্য স্কোপড যেটি কী মালিক।

Studio Image Editor স্টুডিও ইমেজ এডিটর

Built-in image editor with Photoshop-like tools. Available on the master PC's Studio tab. Photoshop-সদৃশ টুলসহ বিল্ট-ইন ইমেজ এডিটর। মাস্টার PC-এর Studio ট্যাবে উপলব্ধ।

Tools টুলস

  • Selection: Marquee, Magic Wand (flood fill)সিলেকশন: মার্কি, ম্যাজিক ওয়ান্ড (ফ্লাড ফিল)
  • Transform: Move, Crop & Rotateট্রান্সফর্ম: মুভ, ক্রপ ও রোটেট
  • Painting: Brush, Eraser, Clone Stamp, Healing Brushপেইন্টিং: ব্রাশ, ইরেজার, ক্লোন স্ট্যাম্প, হিলিং ব্রাশ
  • Objects: Shape, Textঅবজেক্ট: শেপ, টেক্সট
  • Adjustments: Dodge, Burn, Spongeঅ্যাডজাস্টমেন্ট: ডজ, বার্ন, স্পঞ্জ
  • AI: Background Removal (on-device)AI: ব্যাকগ্রাউন্ড রিমুভাল (অন-ডিভাইস)

Print Dialog প্রিন্ট ডায়ালগ

Position, scale, paper size, orientation, margins. Preview matches printed output. Settings persist for next job. পজিশন, স্কেল, পেপার সাইজ, ওরিয়েন্টেশন, মার্জিন। প্রিভিউ প্রিন্টেড আউটপুটের সাথে মিলে যায়। সেটিংস পরবর্তী জবের জন্য পার্সিস্ট হয়।

Troubleshooting ট্রাবলশুটিং

SmartScreen blocks the installer SmartScreen ইনস্টলার ব্লক করে +
Click "More info" → "Run anyway". The app is unsigned (no code signing certificate). This is normal for open-source apps. "More info" → "Run anyway" ক্লিক করুন। অ্যাপটি আনসাইনড (কোড সাইনিং সার্টিফিকেট নেই)। ওপেন-সোর্স অ্যাপের জন্য এটি স্বাভাবিক।
Printer not found প্রিন্টার পাওয়া যায় না +
Ensure the printer is installed in Windows Settings → Printers. Restart the app. Check the Windows Agent window for detected printers. Windows Settings → Printers-এ প্রিন্টার ইনস্টল করা আছে কিনা নিশ্চিত করুন। অ্যাপ রিস্টার্ট করুন। ডিটেক্টেড প্রিন্টারের জন্য Windows Agent উইন্ডো চেক করুন।
WebSocket connection failed WebSocket কানেকশন ফেইল +
Check the token matches on both sides. Ensure the listener is running (master PC). For LAN, verify TLS cert and firewall rules. উভয় পাশে টোকেন মিলছে কিনা চেক করুন। লিসেনার রানিং আছে কিনা নিশ্চিত করুন (মাস্টার PC)। LAN-এর জন্য TLS সার্ট এবং ফায়ারওয়াল রুলস ভেরিফাই করুন।
Counter shows "Not paired" কাউন্টার "Not paired" দেখায় +
Enter the pairing key from the master PC's Counter QR poster. Ensure the master gateway URL is correct (same host:port as QR, without ?shop= query). মাস্টার PC-এর Counter QR poster থেকে পেয়ারিং কী এন্টার করুন। মাস্টার গেটওয়ে URL সঠিক কিনা নিশ্চিত করুন (QR-এর মতো একই host:port, ?shop= query ছাড়া)।
