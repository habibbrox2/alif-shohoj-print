### UI ডিজাইন নীতিমালা (PDF অনুযায়ী)

| বিষয়              | সিদ্ধান্ত                                      |
|-------------------|-----------------------------------------------|
| স্টাইল            | Clean, Minimal, Fluent Design inspired        |
| প্রাইমারি কালার   | Teal (#0F766E) + Green (#10B981)              |
| ফন্ট              | Segoe UI / Inter                              |
| ভাষা              | বাংলা (ডিফল্ট) + English টগল                  |
| Agent             | Tray-based, background, auto-start            |
| নোটিফিকেশন        | Windows Toast + বাংলা সাউন্ড + Badge          |
| Settings          | Server-authoritative + Offline cache          |
| Accessibility    | বড় বাটন, সহজ বাংলা, ভয়েস গাইড                |
